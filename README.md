## ✨ About Me

I am **Mouaz Naji**, a Software Engineering student at **Blekinge Institute of Technology**. I build software across backend services, systems programming, databases, mobile development and AI-assisted engineering workflows.

My strongest work sits where engineering depth matters most: **architecture, correctness, reliability, synchronization, performance and secure delivery**.

```text
🧩 PRIMARY     backend systems · software architecture · generative AI
⚙️ SYSTEMS     Linux · processes · threads · IPC · filesystems · networking
💻 LANGUAGES   Python · C++ · C · Java · TypeScript · JavaScript · Kotlin
🛡️ PRINCIPLES  reliability · security · maintainability · measured performance
```

### 🌟 Engineering Highlights

- 🔥 Backend engineering and scalable application architecture
- 🧠 AI-assisted workflows, agents and controlled automation
