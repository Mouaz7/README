# Installation

Upload the complete `assets` folder and `README.md` to the root of `Mouaz7/Mouaz7`.

```text
Mouaz7/
├── README.md
└── assets/
    ├── hero-dark.svg
    ├── hero-light.svg
    ├── architecture-dark.svg
    ├── architecture-light.svg
    ├── capabilities-dark.svg
    ├── capabilities-light.svg
    ├── projects-dark.svg
    ├── projects-light.svg
    ├── roadmap-dark.svg
    └── roadmap-light.svg
```

The README uses GitHub dark/light theme detection through `<picture>` elements.
